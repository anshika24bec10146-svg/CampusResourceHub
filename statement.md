# Project Statement

## Project Title
Campus Resource Hub – Academic Resources & Study Planner

## Problem Statement
College students frequently store notes, PDFs, links, assignments and study schedules across multiple applications. This fragmentation makes academic resources difficult to locate and makes it harder to monitor study progress.

## Scope
The project will provide a centralized web application where authenticated users can:
- organize academic subjects;
- add, edit, delete and search study resources;
- create and manage study tasks;
- track task completion;
- view simple academic progress analytics.

The first version is intentionally limited to academic resource and study-planning functions. Online examination, payment, live classes and advanced AI tutoring are outside the initial scope.

## Target Users
- College students
- Student project teams
- Optional future users: faculty/admin

## High-Level Features
1. User authentication and profile management.
2. Subject and resource management.
3. Study planner and task tracking.
4. Progress dashboard and analytics.
5. Validation, error handling and testing.
